Benchmark

Times the library in this browser on the same image at four sizes, with the 1000 best keypoints, so numbers compare across machines and with the native backends. A run is one call into the library: copying the pixels in, the network, keypoint selection, descriptors and reading the results back. The table shows the median of the timed runs, after warm-up runs. Keep this tab in front while it runs: browsers slow down hidden tabs.
