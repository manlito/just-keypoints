just-keypoints in the browser

Runs the WebAssembly module on WebGPU (FP32, and FP16 when the adapter has shader-f16) and on its CPU backend, and compares each result with the native CPU backend on the same pixels (testdata/). FP32 must give the same keypoints in the same order (position within 0.01 px, score within 1e-4, descriptor cosine at least 0.9999); FP16 at least 97 % of the keypoints within 1 px.
